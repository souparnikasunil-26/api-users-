# User Cards App

## Objective

Learn API calls using JavaScript using Fetch API, Async/Await, and JSON.

## Features

* Fetches user data from the JSONPlaceholder API
* Displays users in responsive cards
* Uses Async/Await
* Implements error handling

## API Used

https://jsonplaceholder.typicode.com/users

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Run

1. Clone the repository
2. Open `index.html` in a browser
3. Users will be loaded from the API automatically

## Acceptance Criteria

* API data displayed correctly
* Error handling implemented
* GitHub repository submitted
